## Featured projects

### 🪐 [Marswalk](https://github.com/zhengyutong99/Marswalk-SpaceApps-2026) · [play it in your browser](https://zhengyutong99.github.io/Marswalk-SpaceApps-2026/)
A Mars EVA planner built for NASA Space Apps Challenge 2026. Plan a route across real HiRISE terrain — the A* planner reports distance, O₂ margin, radiation dose, sand-trap risk and walk-back limit, then gives a GO / NO-GO verdict — and rehearse it in first person through a helmet HUD.
`Three.js` `Python` `NASA PDS data`

### 🧬 [GTCN-DCA](https://github.com/zhengyutong99/GTCN)
Graph Transformer-Convolution Network that predicts drug–cancer associations from a drug–target–pathway–disease graph, with a dataset of 2,614 drugs, 20,501 targets, 8,208 pathways and 455 diseases.
`PyTorch` `Graph neural networks`

### ⚡ [GPU acceleration for iGEMDOCK](https://github.com/zhengyutong99/Parallel-Programming)
CUDA port of the fitness-evaluation step in a molecular docking program — the pairwise ligand–cavity energy computation that dominates virtual screening runtime.
`C++` `CUDA`

### 🏎️ [Vision-based racecar agent](https://github.com/zhengyutong99/Reinforcement-Learning)
RL agent that drives from a single RGB frame per timestep in racecar_gym, using frame stacking, recurrent policies and reward shaping to handle partial observability.
`Python` `PyTorch`

### 🌏 [Taiwan utility monitor](https://github.com/zhengyutong99/Cloud-Native-Development-Project)
Containerised microservices that crawl earthquake, power-grid and reservoir open data, raise severity-ranked alarms and show them on a dashboard.
`Docker` `Firestore` `JavaScript`

## Featured projects

### 🪐 [Marswalk](https://github.com/zhengyutong99/Marswalk-SpaceApps-2026) · [play it in your browser](https://zhengyutong99.github.io/Marswalk-SpaceApps-2026/)
A Mars EVA planner built for NASA Space Apps Challenge 2026. Plan a route across real HiRISE terrain — the A* planner reports distance, O₂ margin, radiation dose, sand-trap risk and walk-back limit, then gives a GO / NO-GO verdict — and rehearse it in first person through a helmet HUD.
`Three.js` `Python` `NASA PDS data`

### 🧬 [GTCN-DCA](https://github.com/zhengyutong99/GTCN) · first-author paper, under revision at *Bioinformatics*
Interpretable Graph Transformer-Convolution Network that predicts drug–cancer associations from a drug–target–pathway–disease graph (2,614 drugs, 20,501 targets, 8,208 pathways, 455 diseases). About 2× F1 over the baseline at comparable AUC.
`PyTorch` `Graph neural networks`

### ⚡ [GPU acceleration for iGEMDOCK](https://github.com/zhengyutong99/Parallel-Programming)
CUDA port of the fitness-evaluation step in a molecular docking program — the pairwise ligand–cavity energy computation that dominates virtual screening runtime. Up to 2× faster than the CPU baseline.
`C++` `CUDA`

RL agent that drives from a single RGB frame per timestep in racecar_gym, using frame stacking, recurrent policies and reward shaping to handle partial observability.
`Python` `PyTorch`
